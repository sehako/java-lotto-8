# 로또 발매기

# 개요

로또 발매기 시뮬레이터입니다. 당첨 기준과 금액은 다음과 같습니다.

- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원

# 사용 방법

로또 발매기 사용 방법입니다. 다음과 같은 방법으로 사용해주세요

## 로또 구입 금액 입력

프로그램의 안내에 따라서 로또 구입 금액을 입력합니다. 이때 1,000원 단위의 금액을 입력해야 하며, 잘못 입력된 경우에는 오류가 발생하고 구입 금액을 다시 입력해야 합니다. 구입 금액이 정상적으로 입력된 경우에는
다음과 같이 로또가 발급됩니다.

```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```

## 당첨 번호 입력

로또를 구입한 이후 당첨 번호를 입력합니다. 번호는 쉼표를 기준으로 분리하며 6개의 당첨 번호를 입력해야 합니다. 만약 잘못된 당첨 번호를 입력할 경우 오류가 발생하며 당첨 번호를 다시 입력해야 합니다.

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

## 보너스 번호 입력

당첨 번호를 입력한 이후에는 보너스 번호를 입력합니다. 보너스 번호는 1부터 45까지의 숫자 중 하나를 입력하며, 잘못 입력한 경우 오류 메시지가 출력되며 다시 보너스 번호를 입력해야 합니다.

```
보너스 번호를 입력해 주세요.
7
```

## 당첨 통계 출력

입력한 당첨 번호와 보너스 번호에 따라서 당첨 통계를 계산합니다. 앞서 입력된 당첨 번호와 보너스 번호에 대한 당첨 통계는 다음과 같습니다.

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

# 구현 사항

## 로또 발급

- `구입금액을 입력해 주세요.`을 출력하고 구입금액을 입력받는다.
- 구입금액을 검증한다.
    - 숫자 이외의 값 (E1)
    - 음수 (E2)
    - 0으로 시작하는 숫자 (E3)
    - 1000원 단위가 아닌 금액 (M1)
    - 20억 이상의 금액 (M2)
    - -2,147,483,648 ~ 2,147,483,647 범위를 넘은 금액 (M3)
- 검증 실패 시 다시 입력받도록 한다.
- `n개를 구매했습니다.`를 출력하고 발급한 로또 번호를 출력한다. `n`은 발급한 로또의 개수이다.

## 당첨 번호 입력

- `당첨 번호를 입력해 주세요.`를 출력하고 당첨 번호를 입력받는다.
- 당첨 번호를 `,` 기준으로 나눈다.
- 당첨 번호를 검증한다.
    - 당첨 번호가 6개가 아님 (W1)
    - 숫자 이외의 값 (E1)
    - 음수 (E2)
    - 0으로 시작하는 숫자 (E3)
    - 1 ~ 45 사이가 아닌 값 (E4)
    - 중복된 당첨 번호 (W2)
- 검증 실패 시 다시 입력받도록 한다.

## 보너스 번호 입력

- `보너스 번호를 입력해 주세요.`를 출력하고 보너스 번호를 입력받는다.
- 보너스 번호를 검증한다.
    - 숫자 이외의 값 (E1)
    - 음수 (E2)
    - 0으로 시작하는 숫자 (E3)
    - 1 ~ 45 사이가 아닌 값 (E4)
    - 당첨 번호와 중복 (B1)
- 검증 실패 시 다시 입력받도록 한다.

## 당첨 통계 계산 및 출력

- 당첨 번호와 보너스 번호에 따라서 당첨된 로또 개수와 당첨금을 계산한다.
- 로또 구입금액과 당첨금으로 수익률을 계산한다. (수익률은 소수점 둘째 자리에서 반올림한다.)
